## PERF-001: what changed on `welcome.html`

- **Head scripts**
  - `lottie-player`, ScrollMagic (CDN) and crypto-js are now `defer`.
  - webfontloader is now `async`, using `WebFontConfig`. The duplicate inline `WebFont.load` was removed.
  - The inline `new ScrollMagic.Controller()` became an inline `type="module"` script. Module scripts run in document order with the deferred scripts, so ScrollMagic is loaded before it runs. The controller is set on `window`.
- **Font CSS:** Typekit and Google Roboto (now `&display=swap`) are non-blocking (`media="print" onload`), with a `<noscript>` fallback.
- **Body scripts**
  - All 5 Firebase 8.10.1 SDK scripts and the 35 local jQuery/plugin/runwaejs scripts are now `defer`.
  - The inline Firebase init and the ScrollMagic scenes script became `type="module"`, so their order is kept. `analytics` and `database` are set on `window`.
  - xps check: `jQuery`, `window.database`, `window.controller` and `lottie-player` are all defined, and there are no page errors at 1280 or 375. That matches the baseline.
- **fontawesome-all.js (245KB) is no longer loaded on welcome.** The 4 footer social icons were already inline SVG (the `<i>` tags are commented out), so the subset that works is zero icons. The `.svg-inline--fa` sizing CSS is inlined; icon width is 13.1px before and after.
- **LCP:** the LCP element is the `h1.welcomeTitle` text, not an image, so there was no LCP image to preload. The gain comes from removing the blocking chain. The header logo is no longer `loading="lazy"` and has `fetchpriority="high"`. Below-the-fold `<img>` already had `loading="lazy"`.
- **Trade-off:** lab TBT went from 368ms to 952ms. The same scripts still run, but now inside the measured window after first paint, and nothing blocks render any more.
